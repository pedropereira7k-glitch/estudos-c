# Estudos em C

Repositório com exercícios de programação em C utilizando `struct`, vetores,
funções, buscas, ordenação e manipulação de strings.

## Conteúdo

### Cadastro de alunos

Arquivo sugerido: `alunos.c`

- Cadastro de alunos
- Busca por matrícula
- Listagem de alunos
- Cálculo de média
- Separação entre aprovados e reprovados
- Ordenação por nome

### Cadastro de clientes

Arquivo sugerido: `clientes.c`

- Cadastro de clientes
- Listagem de clientes
- Busca sequencial por nome
- Busca por código
- Armazenamento de nome, cidade e renda

### Cadastro de funcionários

Arquivo sugerido: `funcionarios.c`

- Cadastro de funcionários
- Busca por nome
- Busca por matrícula
- Listagem de funcionários
- Cálculo da média salarial
- Busca por salário mínimo
- Busca de funcionários acima da média
- Ordenação por salário e nome
- Aplicação de aumento salarial

### Cadastro de produtos

Arquivo sugerido: `produtos.c`

- Cadastro de produtos
- Busca por descrição
- Busca por ID
- Ordenação por preço, descrição e ID
- Identificação do produto mais caro
- Identificação do produto mais barato

### Cadastro de livros

Arquivo sugerido: `livros.c`

- Cadastro de livros
- Busca por título
- Busca por código
- Listagem de livros
- Identificação de livros em falta
- Ordenação por preço

### Cadastro de veículos

Arquivo sugerido: `veiculos.c`

- Cadastro de veículos
- Busca por modelo
- Busca por placa
- Listagem de veículos
- Busca de veículos anteriores a determinado ano
- Cálculo da média de valor
- Identificação de veículos acima da média
- Ordenação por ano e valor
- Aplicação de depreciação

## Conceitos praticados

- Estruturas (`struct`)
- Vetores de estruturas
- Funções
- Busca sequencial
- Busca binária
- Ordenação por seleção
- Strings
- `strcmp`
- `strcspn`
- Entrada e saída de dados
- Laços de repetição
- Condicionais
